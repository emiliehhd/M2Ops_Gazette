# Contribuer

## Branches
- `main` est protégé : pas de push direct, une revue avant de fusionner.
- Une branche par sujet : `feat/…`, `fix/…`, `docs/…`, `chore/…`.

## Commits
Format : `type(portée): message` ; ex. `feat(collecte): lire le flux Le Monde`.
Types : feat, fix, docs, test, chore.

## Revue et fusion
- Toute fusion passe par une pull request relue par une autre personne.
- La CI doit être verte avant de fusionner.
- L'auteur·e de la PR fusionne (squash).
